# Channel norms — one post, three native shapes

Read only the sections for the channels chosen in Step 1. The **angle and core claim stay identical** across every channel. What changes: length, line rhythm, hashtag load, hook truncation, CTA placement.

---

## LinkedIn

**Reader mindset:** professional feed, scrolling between meetings. Values insight, specifics, and a human behind the brand. Allergic to corporate broadcast and hustle-guru energy.

- **Truncation:** the feed cuts around 140 characters before "…more". The hook plus enough tension to earn the click must live above that line.
- **Length:** 900–1,500 characters is the workable range. Depth is rewarded, but one idea per line.
- **Formatting:** generous line breaks (blank line between thoughts). No walls of text. No markdown — LinkedIn renders it literally.
- **Hashtags:** 0–3, at the very bottom, niche not broad (`#b2bmarknadsföring`, not `#marketing`).
- **CTA:** a comment prompt or the comment-keyword lead-magnet CTA works best. Links in the post body suppress reach — put a link in the first comment and say so.
- **Voice:** first person, specific, a point of view. A named number or tool beats an adjective.

**Skeleton:**
```
[Hook line — VoC pain or contrarian claim, works before the "…more" cut]

[One idea per line, blank line between beats. Build from the reader's words.]

[Handle the obvious objection in a line.]

[CTA — comment keyword or a real question]
#niche #niche2
```

## Instagram

**Reader mindset:** visual-first, faster scroll, warmer and more personal than LinkedIn. The image already did the stopping; the caption keeps them.

- **Truncation:** feed truncates the caption very early (~125 characters). Line 1 must be the hook, no warm-up.
- **Length:** shorter than LinkedIn. Tight caption, warmer tone. Story flow, one idea per line.
- **Hashtags:** 3–8 niche tags. Put them in the first comment or after a few blank-line "dots" so they don't clutter the caption. Never 30 broad tags.
- **Emoji:** only if `brand-guidelines.md` permits them; then sparingly as visual anchors, never as a substitute for a word.
- **CTA:** comment-keyword CTA (→ DM → lead magnet) is native here. "Link in bio" only when a real destination exists.
- **Voice:** personal, direct address ("du"), conversational.

**Skeleton:**
```
[Hook line — the strongest first, feed cuts early]

[Warm, one idea per line. Story beat or lesson.]

[CTA — comment keyword or a question]
.
.
.
#niche1 #niche2 #niche3
```

## X / Twitter

**Reader mindset:** fastest scroll, lowest patience, highest reward for a sharp single line. Threads for depth, single post for a punch.

- **Length:** the hook is the whole game. One punchy post (≤280 chars) or a short thread where tweet 1 is a standalone hook that earns the thread.
- **Formatting:** no line-break padding for its own sake. Tight. Every word carries weight.
- **Hashtags:** 0–1. Hashtag clutter reads as spam here.
- **Links:** a link in the main post can suppress reach — put the link/CTA in a reply and point to it ("link below").
- **CTA:** soft (a question, a "bookmark this") or the keyword-in-reply move. Hard sells underperform.
- **Voice:** blunt, confident, a little contrarian. No hedging.

**Skeleton (single):**
```
[Hook = the whole claim, self-contained, ≤280 chars]
```

**Skeleton (thread):**
```
1/ [Standalone hook that earns the thread]
2/ [One idea]
3/ [One idea]
…/ [Payoff]
[reply] [CTA + link]
```

## Cross-channel checklist

- Same angle, same core claim on all three. If the claim drifts, you wrote three posts — fix it.
- Hook re-tuned per truncation limit (140 LinkedIn / 125 Instagram / whole-post X).
- Hashtag load matched to channel (0–3 / 3–8 / 0–1).
- CTA placement matched (comment/first-comment link / first comment tags / reply link).
- Humanizer pass run on every variant independently.
